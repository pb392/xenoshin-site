Elestrals Meta Assistant

Ask a question about the competitive Elestrals card game and get a short answer that links to the exact tournament result, decklist or note it came from.

Open the app Read the code
Status (Build stage, November 2026): import, search and cited answers are working and hosted. The full case study, measured results and accessibility checks come at the release stage in December. This page says only what has been built so far.

The problem

Players preparing for a tournament want to know what's winning, but the information is scattered across official articles, community results sites and people's own notes. A general chatbot may confidently invent decklists. This app answers only from sources it has imported, and says so when it can't.

How it works

  1. Import: four permitted sources are loaded with stable IDs, versions and a verification status. Running the import again changes nothing.
  2. Represent: text is split into small passages (with keyword and meaning-based search indexes). Tournament results, decklists and which archetypes play which boss go into database tables, because exact counts and relationships are a poor fit for similarity search.
  3. Retrieve: each question gets keyword and vector search results, merged together, plus exact database lookups.
  4. Answer: Google Gemini writes a short answer using only that evidence. The app then checks every citation, removes any that don't match, and withholds answers with no valid citation.

Decisions I made

DecisionWhy
Database tables + vector search, not vectors aloneQuestions like "how many copies of a card" or "which decks run this boss" need exact answers.
SQLite, not PostgreSQL or Neo4jMy server has 1 GB of RAM. SQLite is a single file with no extra service.
Hosted embeddings (Gemini)A local embedding model could use most of that 1 GB by itself.
Every fact marked "externally verified" or "author knowledge"A classmate's review pointed out that my own notes agreeing with themselves isn't confirmation.
No player names storedPlacements are stored by position only; the app doesn't need personal data.

Evidence

  • Live app: ask a question, then open "How this answer was found" to see the full trace.
  • Source list and import record
  • Automated tests (GitHub Actions), which must pass before the server updates
  • Research and planning record

Limits right now

  • The data is small: one official Worlds summary, one Premier's top 8 with the winning decklist, and two sets of my own notes.
  • The Columbus Open results come only from my notes until TopElestrals posts them.
  • A citation shows where an answer came from; it doesn't guarantee every sentence is right.
