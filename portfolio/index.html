Why the site looks like this

Research finding: the three game-studio postings I studied (2K, and two Epic Games internships) all ask for C++, and Epic's tools internship turned out to be C++ engine work. So this site leads with what I can already prove (tested services and release pipelines, each with linked evidence) and lists a C++ tool as the next project instead of claiming skills I can't show yet.

I put projects first because someone reviewing many applicants should reach real work in one click. That's my hypothesis about reviewers, not something I've measured.
